# Мой день

Личный трекер в виде Telegram Mini App: сон, состояние, привычки, спорт, учёба, здоровье, деньги и дела, с графиками за 7, 30 и 90 дней.

Записи хранятся в облачном хранилище Telegram (CloudStorage), отдельный сервер не нужен. Вне Telegram страница сохраняет данные в браузере.

Хостинг: GitHub Pages из ветки `main`, корень репозитория.
